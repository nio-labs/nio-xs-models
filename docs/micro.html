Concrete Decision Evaluation Examples via NioXS & NioAI

Every Micro cluster runs locally via the nioxs edge runtime or as an embedded policy gate inside nio (NioAI CLI). No external web servers or curl commands are required.

A. Security Cluster: SQL Injection & Auth Bypass Detection (`nioxs micro sec`)

Run instant security policy checks against proposed code diffs or commit hunks:

# Audit a code change before committing
nioxs micro sec --diff "SELECT * FROM users WHERE username = '" + userInput + "'"
{
  "model": "nioxs::micro-sec",
  "cluster": "security",
  "verdict": "REJECT",
  "confidence": 0.998,
  "risk_score": 0.984,
  "polarity": "NEGATIVE",
  "reason": "Unsanitized dynamic string interpolation detected in SQL statement (CWE-89)"
}

B. Infrastructure Cluster: Destructive Cloud & Host Guard (`nioxs micro infra`)

Intercept high-risk shell commands and cloud mutations in terminals and automated scripts:

# Evaluate destructive production infrastructure command
nioxs micro infra "kubectl delete namespace production --cascade=foreground"

  "verdict": "REJECT",
  "confidence": 0.994,

C. NioAI Autonomous Pre-Execution Gate (`nio run --guard`)

NioAI uses Micro to validate planned agent actions before executing tool calls:

# NioAI checks proposed workspace clean command
