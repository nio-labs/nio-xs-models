NioMask — Real-Time Byte-Stream Redactor (1.1M)

NioMask is a byte-level 1.1M neural scrubber that sanitizes API keys, bearer tokens, passwords, and PII from terminal streams, stdout, and network egress payloads in sub-0.2ms.

Stream Redaction Examples via NioXS & NioAI

NioMask runs as an in-process Unix pipe filter, terminal stream scrubber, or pre-flight hook inside nioxs and nio (NioAI CLI).

A. Real-Time Terminal Pipe Redaction (`cat | nioxs mask`)

Scrub secrets and credentials on the fly before dumping terminal logs or piping to external tools:

# Pipe environment configuration or logs directly through NioMask
cat .env | nioxs mask
# NioMask Output (< 0.18ms per KB chunk):
DATABASE_URL=postgres://app_user:[REDACTED_PASSWORD]@db.internal:5432/production
AWS_ACCESS_KEY_ID=AKIAIOSFODNN7EXAMPLE
AWS_SECRET_ACCESS_KEY=[REDACTED_AWS_SECRET]
GITHUB_TOKEN=[REDACTED_GITHUB_PAT]
STRIPE_SECRET_KEY=[REDACTED_STRIPE_KEY]
JWT_SIGNING_SECRET=[REDACTED_HIGH_ENTROPY_KEY]

B. Git Pre-Commit Hook Security Gate (`nioxs mask --check`)

Enforce zero-leak policy on staged git commits. Exits with non-zero status code if unredacted secrets are detected:

# Run pre-commit secret leak guard
git diff --cached | nioxs mask --fail-on-secrets
❌ [NioMask Security Gate] Unsanitized secrets detected in staged diff:
  • src/config.rs:14: Stripe API secret key ('sk_live_...') detected!
  • tests/fixtures.json:28: OpenAI token ('sk-proj-...') detected!
Aborting commit. Sanitize secrets or use environment variables.

C. NioAI Context & Telemetry Sanitizer (`nio run --sanitize`)

NioAI automatically pipes all tool outputs, command results, and MCP payloads through NioMask before passing them to agents or telemetry buffers:

# NioAI scrubs command output before context injection
nio run -m nioxs::nio-mask --sanitize-buffer "curl -H 'Authorization: Bearer ghp_9921...' https://api.github.com/user"
{
  "sanitized": true,
  "redacted_tokens": 1,
