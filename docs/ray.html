2. AST-µLM Core Architectural Pillars

AST-MicroLM decouples neural matrix multiplication from static memory bloat through four first-principles breakthroughs:

⚡

1. Tree-sitter Candidate Slicing

Compiler grammars deterministically dictate valid syntax at any cursor position (only ~40 tokens out of 151,936 are syntactically legal). We compute dot-products only for valid candidate rows, sampling in 0.04 ms (40 µs) and bypassing the 544 MB uncompressed vocab head.

40 µs Reflex • Bypasses 544MB Head
🌊

2. Streaming Layer Eviction

Transformers execute layers strictly sequentially. Rather than keeping all 24 layers in RAM simultaneously, the streaming engine holds only 1 layer (~8.5 MB) in physical RAM at any instant, evicting completed layers immediately via memory-mapped sliding window.

~8.5 MB Active Layer Window
📐

3. Clean 32-Byte Block Quantization

Qwen's hidden dimension $d=896$ is divisible by 32 ($896 / 32 = 28$). Clean 32-block Q4_0 compresses the entire model to 265.25 MiB with zero fallback warnings and pure AVX-512 / AVX2 SIMD acceleration.

265.25 MiB • 0% Fallback Overhead
🛡️

4. Standalone & Air-Gapped

Pure freestanding Rust binary using direct memory-mapped SIMD kernels. Zero external dependencies, no Python server, no niodb, no niojs, and zero cloud API keys.

Zero Daemons • 100% In-Process

5. Quickstart & Execution

1. Download certified NioRay AST-µLM model and stock tokenizer:

mkdir -p models
curl -fL https://github.com/nio-labs/nio-xs-models/releases/download/v0.4.1/nio-ray-ast.Q4_0.gguf -o models/nio-ray-ast.Q4_0.gguf
curl -fL https://github.com/nio-labs/nio-xs-models/releases/download/v0.4.1/tokenizer.json -o models/tokenizer.json

2. Run via native AST-µLM Rust streaming runtime (Sub-85MB startup):

cargo run --release --package nio-ray-runtime -- \
  --model models/nio-ray-ast.Q4_0.gguf \
  --tokenizer models/tokenizer.json \
  --prompt "Write an in-memory thread-safe LRU cache in Rust using Arc and Mutex."

3. Or execute via standard NioXS CLI:

nioxs pull ray
nioxs ray "Write a TypeScript function to parse and validate JWT claims"
