2. AST-µLM Core Architectural Pillars

AST-MicroLM decouples neural matrix multiplication from static memory bloat through three first-principles breakthroughs:

1. Tree-sitter Candidate Slicing

Compiler grammars deterministically dictate valid syntax at any cursor position (e.g., only ~40 tokens out of 151,936 are syntactically legal). We compute dot-products only for valid candidate rows, sampling in 0.04 ms (40 µs) and bypassing the 544 MB uncompressed vocab head.

2. Sliding-Window Layer Eviction

Transformers execute layers strictly sequentially. Rather than keeping all 24 layers in RAM simultaneously, the streaming engine holds only 1 layer (~8.5 MB) in physical RAM at any instant, evicting completed layers immediately via libc::malloc_trim(0).

3. Clean 32-Block Quantization

Qwen's hidden dimension $d=896$ is not divisible by 256, causing standard k-quants (Q4_K_M) to fall back and bloat to 373 MB. Clean 32-block Q4_0 ($896 / 32 = 28$) compresses the entire artifact to 265.25 MiB with zero fallback warnings.

4. Standalone & Air-Gapped

Pure freestanding Rust binary using direct memory-mapped SIMD kernels. Zero external dependencies, no Python server, no niodb, no niojs, and zero cloud API keys.

5. Quickstart & Execution

# 1. Download certified NioRay AST-µLM model and stock tokenizer
mkdir -p models
curl -fL https://github.com/nio-labs/nio-xs-models/releases/download/v0.4.1/nio-ray-ast.Q4_0.gguf -o models/nio-ray-ast.Q4_0.gguf
curl -fL https://github.com/nio-labs/nio-xs-models/releases/download/v0.4.1/tokenizer.json -o models/tokenizer.json

# 2. Run via native AST-µLM Rust streaming runtime (Sub-85MB startup)
cargo run --release --manifest-path crates/nio-ray-runtime/Cargo.toml

# 3. Or execute via standard llama.cpp / llama-cli
llama-cli -m models/nio-ray-ast.Q4_0.gguf -p "<|im_start|>user\nWrite a hello world in Rust.<|im_end|>\n<|im_start|>assistant\n"
