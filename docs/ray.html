2. AST-µLM Core Architectural Pillars

AST-MicroLM decouples neural matrix multiplication from static memory bloat through four first-principles breakthroughs:

⚡

1. Candidate-Row Projection

The engine projects only the candidate rows supplied by its caller. The tested CLI AST mode uses a fixed 27-token pool from a Rust example; grammar integration and syntactic correctness are not measured by this session.

27 CLI Candidates • Caller-Supplied Pools
🌊

2. Streaming Layer Eviction

The runtime loads layers sequentially, drops each layer’s CPU weights after use, and advises away completed mmap ranges. Total process RSS also includes the tokenizer, RoPE tensors, KV cache, masks and allocations.

Sequential Layer Loading & Eviction
📐

3. Q4_K_M & Q4_0 Quantization

Supports both Q4_K_M (balanced medium quantization, 373 MiB) and verified release Q4_0 (270.93 MiB). Norms and biases retain full stored precision with host-native SIMD kernels.

Q4_K_M / Q4_0 • Native CPU SIMD
🛡️

4. Standalone & Air-Gapped

Pure freestanding Rust binary using direct memory-mapped SIMD kernels. Zero external dependencies, no Python server, no external daemons, and zero cloud API keys.

Zero Daemons • 100% In-Process
🌊

5. Overlapped Prefetch & Batch Eviction

As layer $N$ computes forward passes, layer $N+1$ is asynchronously paged in via MADV_WILLNEED. Layers are evicted in pairs, cutting kernel syscalls in half while strictly staying under 100 MB RAM.

Overlapped I/O • < 100 MB Hard Cap
⚡

6. PhraseBuffer & Fluid Typewriter Flow

Emits tokens via an adaptive 4-word / 32-character boundary-aware PhraseBuffer, paired with NioAI's client-side fluid character-level typewriter stream rendering.

PhraseBuffer SSE • Fluid Terminal Typing

4. Streaming Architecture & Fluid Typewriter Flow

NioRay pairs native in-process engine streaming with NioAI's decoupled typewriter terminal renderer to deliver an uninterrupted, zero-flicker typing flow:

🌊

Overlapped Pipeline Prefetch

As layer $N$ computes attention and MLP feed-forward operations, layer $N+1$ is asynchronously paged into CPU cache via kernel MADV_WILLNEED. Layers are evicted in pairs (MADV_DONTNEED) to cut syscalls in half while strictly staying under 100 MB resident RAM.

Overlapped I/O • < 100 MB Ceiling
⚡

Adaptive PhraseBuffer (SSE)

The engine buffers output tokens into cohesive 4-word / 32-character phrases, immediately flushing on code blocks (```), newlines, XML tags, and sentence terminators (. , ! , ? ) to avoid choppy single-token network packet fragmentation.

PhraseBuffer SSE • 4 Words / 32 Chars
⌨️

Decoupled Fluid Typewriter (NioAI)

NioAI receives SSE chunks asynchronously into an unbounded queue, while an independent typewriter task continuously drains characters to the terminal at 9–13ms cadence. Network packet stalls are bridged seamlessly, producing a hypnotic typewriter effect.

Decoupled Queue • Zero Network Stalls
🛡️

Atomic ANSI Escape Handshake

Color styling (\x1b[38;5;...m), bold, and frame borders are emitted as atomic units with 0ms delay, preventing terminal cursor flickering, line breaks, or escape leakage.

Zero Flicker • Clean Terminal Borders
