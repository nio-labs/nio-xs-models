NioRay — Electric Keystroke Reflex Predator (Based on Qwen 2.5 Coder)

NioRay is the flagship Keystroke Predator in Nio's Predator Fleet. Built for local code completions and short code transformations, it executes 100% in-process within nio-xs via native Rust Candle tensor kernels—requiring zero Ollama, zero external daemons, and zero cloud API fees.

Ecosystem Role: Flagship of The Predator Fleet

NioRay targets local code completions and short transformations. Performance depends on hardware, prompt length, cache state, and runtime. Reproducible latency, throughput, and resident-memory benchmarks are pending.

Foundational Heritage: Based on Qwen 2.5 Coder

NioRay is built upon the proven architecture of Qwen/Qwen2.5-Coder-0.5B-Instruct (24 transformer layers, $d_{\text{model}} = 896$, 14 attention heads, 2 KV heads). We specialize the weights for in-process developer reflex speed and ground it with Nio's deterministic memory and calculation engines.

3. How NioRay Works with NioAI

NioAI is Nio's autonomous agent framework for terminal workspaces, IDEs, and automated developer pipelines. Instead of routing every token through sluggish, high-latency cloud APIs, NioAI employs NioRay as its embedded high-speed co-processor.

NioRay is intended for local short-form coding tasks. Task coverage and cloud-token savings have not been measured.

Key Synergies in NioAI

  • Local execution: NioAI communicates with NioRay via native in-process Rust bindings (`Candle`) or local Unix domain sockets (`~/.nioxs/nioxs.sock`). In-process execution avoids network transport; inference and loading still have costs.
  • Tool delegation: Training examples use <nio_db> and <nio_js> tags. Host interception, execution, and result feedback are required; the standalone Candle generator does not execute these tags.
  • Context reduction: This is an integration goal. No measured cloud-token savings or type-correctness guarantee is available.

5. Concrete Triad Execution Examples via NioXS & NioAI

The following illustrative examples show intended model and host behavior via nioxs ray (direct C-bindings / Candle Rust) or nio run -m nioxs::... (NioAI agent runner). No external daemons or cloud keys required.

A. Real-Time Keystroke Reflex via NioXS CLI (`nioxs ray`)

Instantaneous code synthesis without conversational greeting or explanation fluff:

# Direct in-process keystroke reflex (latency benchmark pending)
nioxs ray "Write an Axum SSE streaming route that broadcasts Redis pub/sub messages"
// <think>
// Direct Server-Sent Events route using axum::response::sse::Event and tokio_stream.
// </think>

use axum::{
    response::sse::{Event, KeepAlive, Sse},
    routing::get,
    Router,
};
use futures::stream::Stream;
use std::convert::Infallible;
use tokio_stream::wrappers::BroadcastStream;

pub fn sse_router(tx: tokio::sync::broadcast::Sender<String>) -> Router {
    Router::new().route("/events", get(move || {
        let rx = tx.subscribe();
        let stream = BroadcastStream::new(rx).filter_map(|res| async move {
            res.ok().map(|msg| Ok::<_, Infallible>(Event::default().data(msg)))
        });
        Sse::new(stream).keep_alive(KeepAlive::default())
    }))
}

B. Ultra-Lean In-Process Reflex via NioAI (`nio run -m nioxs::nio-ray-dev`)

Illustrative output for the 32k truncated-vocabulary Dev model (resident memory has not been benchmarked):

# Run zero-token agent reflex task in NioAI
nio run -m nioxs::nio-ray-dev "Write a TypeScript function to parse and validate JWT claims without third-party dependencies"
/*
<think>
Pure web-crypto base64url decoding and JSON payload parsing.
</think>
*/

export interface JwtClaims {
  sub: string;
  exp: number;
  [key: string]: unknown;
}

export function parseJwtClaims(token: string): JwtClaims {
  const parts = token.split('.');
  if (parts.length !== 3) throw new Error("Invalid JWT token format");
  const payloadBase64 = parts[1].replace(/-/g, '+').replace(/_/g, '/');
  const jsonStr = decodeURIComponent(
    atob(payloadBase64).split('').map(c => '%' + ('00' + c.charCodeAt(0).toString(16)).slice(-2)).join('')
  );
  const claims = JSON.parse(jsonStr) as JwtClaims;
  if (claims.exp && claims.exp * 1000 < Date.now()) {
    throw new Error("JWT token has expired");
  }
  return claims;
}

C. Epistemic Memory Delegation via NioDB (<nio_db>)

A host implementing the delegation protocol can intercept <nio_db> and return project symbols. This illustrative transcript is not a measured execution:

# Run grounded agent synthesis via NioAI
nio run -m nioxs::nio-ray "Create an Axum 0.8 router with health check and graceful shutdown"
// NioRay Co-Process Stream:
// <think>
// Need verified signature for axum::serve and TcpListener in Axum 0.8.
// </think>
// <nio_db query="axum::serve" />
// <nio_db_result>
// pub async fn serve<M, S>(tcp_listener: tokio::net::TcpListener, make_service: M) -> Result<(), std::io::Error>
// </nio_db_result>
// <think>
// Signature verified. Bind TcpListener to port 3000 and return Router with shutdown signal.
// </think>

use axum::{routing::get, Router};
use tokio::net::TcpListener;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let app = Router::new().route("/health", get(|| async { "OK" }));
    let listener = TcpListener::bind("0.0.0.0:3000").await?;
    axum::serve(listener, app)
        .with_graceful_shutdown(async {
            tokio::signal::ctrl_c().await.ok();
        })
        .await?;
    Ok(())
}

D. Deterministic Compute Delegation via NioJS (<nio_js>)

Struct alignment padding and byte math are offloaded to NioJS for exact evaluation, preventing token math errors:

# Execute exact memory layout reflex via NioXS CLI
nioxs ray "Calculate struct alignment padding for a 3-byte header followed by a 64-bit pointer in Zig"
// NioRay Co-Process Stream:
// <think>
// Delegate alignment arithmetic to NioJS to avoid token calculation errors.
// </think>
// <nio_js>const align = 8; const offset = 3; return (align - (offset % align)) % align;</nio_js>
// <nio_js_result>5</nio_js_result>
// <think>
// Padding is 5 bytes. Total struct size is 16 bytes. Write Zig struct.
// </think>

const std = @import("std");

pub const AlignedPacket = extern struct {
    magic: [3]u8,
    _pad: [5]u8,
    data_ptr: *const anyopaque,

    comptime {
        std.debug.assert(@sizeOf(AlignedPacket) == 16);
        std.debug.assert(@alignOf(AlignedPacket) == 8);
    }
};
