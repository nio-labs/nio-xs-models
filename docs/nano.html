2. The Directive (--) System: Zero-Token Execution

Developers frequently need terminal actions, AST symbol lookups, or plugin operations that do not require an LLM. When an input prompt begins with double dashes (--), NioNano intercepts the input in < 0.05ms and executes the deterministic directive locally—consuming 0 cloud tokens and introducing 0 latency.

The Token-Saving Principle

Every time you run --bash cargo test or --definitions RayEngine, NioNano saves 5,000–25,000 tokens that other AI tools waste by uploading your entire prompt and file tree to a cloud LLM just to decide to run a shell command.

3. Concrete Directive Usage Examples via NioAI & NioXS

Directives can be executed either directly in terminal commands via nio (NioAI CLI) or within interactive developer sessions, as well as inspected via nioxs nano.

A. In-Session Shell Execution (`--bash`)

Run compilation checks, git status, or build commands without leaving conversation state or spending LLM tokens:

nio "--bash cargo check --locked"

4. Lexical Intent Triage for Natural Language

When the user does not use a -- directive and enters natural language, NioNano's Multinomial Naive Bayes engine classifies intent into one of 7 calibrated actions:

  • read_file: Direct path or inspection queries
  • inspect_project: Workspace layout, crate relations, build tools
  • find_files: Glob scans, directory searches
  • search_code: Symbol lookups and regex greps
  • run_checks: Test execution, linter, formatting
  • clarify: Ambiguous user prompt requiring user confirmation
  • unsupported: Non-developer requests

5. Native Rust Runtime Integration

use nioxs_nano::{Model, Intent};

// Load embedded weights in < 1ms
let model = Model::embedded()?;

// Parse user prompt in sub-100 microseconds
let prompt = "--callers RayEngine";
let intent = model.classify(prompt);

match intent {
    Intent::Directive(d) => println!("Direct execution: {:?}", d),
    Intent::Action(action) => println!("Routed action: {:?}", action),
    Intent::Coding => println!("Proceed to coding engine"),
}
