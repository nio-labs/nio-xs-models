v-µLM (V-MicroLM) — The Tri-Engine Edge Architecture

v-µLM (V-MicroLM) is Nio's proprietary architecture for running ultra-efficient edge and resident models without relying on synthetic Q&A dataset fine-tuning. Instead of degrading reasoning through synthetic samples, v-µLM organizes execution across three complementary mathematical pillars: v-µLM Reflex, v-µLM Vector, and v-µLM Companion.

1. The Three Pillars (Triad)

Conventional edge models often suffer from either heavy memory bloat or catastrophic forgetting caused by fine-tuning on noisy synthetic question-answer datasets. v-µLM eliminates synthetic training entirely by decoupling syntax reflexes from deep semantic reasoning and sovereign companion intelligence:

Pillar 1: v-µLM Reflex — The Instant Grammar & Decision Engine Suite

Target Models: Viper (100M), Nano (~0.5M), Micro (5.0M), Mask (1.1M), Mini (7.1M)
Runtime: Pure-Rust AST candidate reflex engine & lightweight in-process execution.
Core Mechanism: Couples task-dedicated neural architectures with deterministic AST grammars, lexical intent matrices, and policy gates. By enforcing structural constraints and strict classification heads at the token level, the Reflex fleet emits verified syntax, terminal commands, redaction masks, and defect forecasts in sub-0.1ms to sub-20µs with < 28 MB peak resident RAM.

Pillar 2: v-µLM Vector — The Mathematical Codebook Lattice

Target Models: Mako (150M)
Runtime: Vector Quantization (VQ) Codebook Engine with Importance Matrix calibration.
Core Mechanism: Rather than pruning tokens or forcing linear low-rank SVD decompositions that suffer from 30-layer compounding drift, v-µLM Vector quantizes weight tensors into non-linear vector codebooks (IQ3_XXS). This preserves >0.999 layer cosine similarity, live web scraping intelligence, and token scrubbing in under 92 MB on disk.

Pillar 3: v-µLM Companion — Sovereign Edge Companion Intelligence

Target Models: Skate (135M), Manta (494M) & Beluga (1.54B)
Runtime: Sovereign native Rust AST-Micro Engine with Dynamic Layer Streaming & AVX2 Worker Pool.
Core Mechanism: Delivers tiered edge companion intelligence with strict zero-code invariants, structured <manta_plan> execution DAGs, and bit-exact <think>...</think> Chain-of-Thought reasoning proofs. Dynamic OS page eviction (MADV_DONTNEED) keeps process memory ultralight: Skate at < 50 MB peak, Manta at < 235 MB peak, and Beluga at < 295 MB peak RAM ($4.4\times$ lower than stock Qwen) on pure CPU with zero GPU requirement.

  • Tier 2: Manta (494M) — Systems Guru & DAG Architect. High-throughput architectural and RFC planner generating structured <manta_plan> execution DAGs in < 235 MB peak RAM.
